# Tip Calculator 💰

A simple and responsive Tip Calculator web application built using HTML, CSS, and JavaScript. This project helps users quickly calculate the tip amount and total bill amount based on the entered bill value and tip percentage.

---

## 🚀 Features

- Calculate Tip Amount
- Calculate Total Bill Amount
- Input Validation
- Error Message Display
- Responsive Design
- Simple User Interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
